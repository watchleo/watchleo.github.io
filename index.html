Song Pack Studio

Import songs for Retro Music Player v2.5.3. Add audio, match timed lyrics, and export a Minecraft-ready Songs .mcaddon. Audio files are processed on your device.

Compatible with Retro Music Player v2.5.3. Install and enable the base Behavior Pack and Resource Pack first. This tool builds a separate Songs Behavior Pack + Songs Resource Pack that communicates with the base add-on. Use the v2.5.3 base .mcaddon supplied alongside this HTML.

Importing songs does not change the already-installed base add-on; Minecraft still needs the generated Songs packs enabled in your world.

Install in Minecraft Bedrock

  1. Import the supplied Retro Music Player v2.5.3 base .mcaddon into Minecraft, and enable its Behavior Pack + Resource Pack.
  2. Click Build songs for v2.5.3 to export your custom Songs packs.
  3. Open the downloaded .mcaddon with Minecraft.
  4. In world settings, enable all four packs: Retro Music Player BP, Retro Music Player RP, Songs BP, and Songs RP. Then fully exit and reopen the world.

On iPad: save the exported file in Files, then choose Share → Minecraft if available. If importing the combined Songs file fails, use the separate .mcpack downloads shown after building. If your browser changes the extension to .zip, rename it to .mcaddon (or .mcpack) before importing.

Every song you add shows up in the add-on's ADD list in the player menu, where you burn it onto a blank MiniDisc. No song is tied to a disc number and up to 1,000 songs can be imported into a songs pack; each MZ-RH1 holds up to 300 loaded tracks.
Songs are linked by file name: keep a file's name the same when you rebuild, and discs you already burned keep playing it (you can still change the title shown in game). To change songs later, rebuild and import the new Songs pack; select its latest version in world settings if Minecraft keeps the old version.
Only use music you own or have permission to use.
